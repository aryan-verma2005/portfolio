# Aryan Verma - Portfolio

Personal portfolio website for AI/ML, data science, and software engineering
projects.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript;
no build step or package installation is required.

## Publish with GitHub Pages

In the repository on GitHub, open **Settings → Pages**, select **Deploy from a
branch**, choose the `main` branch and `/ (root)` folder, then save. The site
will be available at `https://aryan-verma2005.github.io/portfolio/` after
GitHub Pages finishes deploying.

The private `my photo/` archive is excluded from Git. The website's profile and
project images under `assets/images/` are required by the page and should remain
in the repository.
